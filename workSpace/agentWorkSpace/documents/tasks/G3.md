# G3 — Go2 深度图检查

- 阶段：0.5
- 状态：以 INDEX 为准
- 前置：G2

## 目标
确认 Go2 的深度相机没被头/身体挡住：`near fraction < 0.10`，PNG 能看到地面。

## 涉及文件
- 复制 `reference/go2_migration/check_go2_depth.py` → `WMP/check_go2_depth.py`
- 只允许改 `WMP/legged_gym/envs/go2/go2_amp_config.py` 的 `class depth`

## 步骤
1. `cp /home/l/workSpace/SWAP/reference/go2_migration/check_go2_depth.py /home/l/workSpace/SWAP/WMP/ && cd /home/l/workSpace/SWAP/WMP && python check_go2_depth.py --task=go2_amp --headless`
2. 看终端输出和 `go2_depth.png`。
3. 不合格只调 `depth.position` / `depth.y_angle`：
   - 下半屏全是机身：`position` 的 z 加 0.02~0.04
   - 只看到远处：`y_angle` 改 `[-30,-20]`
   - 深度全是 0.05 左右：`position` 的 x 减到 0.20，或 z 加到 0.13
4. 每次改完重跑，直到 `near fraction < 0.10`。

## 本机冒烟命令
`cd /home/l/workSpace/SWAP/WMP && python check_go2_depth.py --task=go2_amp --headless`

## 验收
- `near fraction < 0.10`。
- `go2_depth.png` 能看出地面从近到远，不是纯黑/纯白/大机身。
- `bottom-row mean` 小于 `top-row mean`，但不低于 0.1 m。

## 禁止事项
- 不动 FOV、`far_clip`、`near_clip`。
- 不改检查脚本让它通过。
- 不用 MuJoCo XML 代替 URDF。
- 不因为图片不好看就调光照/材质；只看几何遮挡。
