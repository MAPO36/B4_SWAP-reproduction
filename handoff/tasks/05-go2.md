# 阶段 0.5 — Go2 迁移与短训练
- 状态：以 `handoff/STATUS.md` 为准
- 入口：`00-env.md` 退出条件全过
- 出口：G0~G3 + 200~500 iter 短训练 + rollout 视频
## 目标
把 A1 换成 Go2；确认 obs=285/action=12、深度相机不遮挡；短训练证明能学。
## 允许改
- 只通过 `wmp_overlay/files/` + `apply.sh` 改 WMP。
- `go2_amp_config.py` 只调 `depth.position` / `depth.y_angle`。
- Go2 资产从 `unitree_rl_gym/resources/robots/go2/` 复制，不进 overlay。
## 步骤
1. G0：资产 → `WMP/resources/robots/go2/`；`go2_amp_config.py`、`legged_gym/envs/go2/__init__.py`、`legged_gym/envs/__init__.py` 注册 `go2_amp` 放 overlay。
2. G1（WMP 根目录，必须 `ALL CHECKS PASSED`）：
```bash
python ../reference/go2_migration/convert_motion_a1_to_go2.py \
  --src datasets/mocap_motions --dst datasets/mocap_motions_go2
python ../reference/go2_migration/check_motion_order.py \
  --src datasets/mocap_motions --dst datasets/mocap_motions_go2
```
3. G2（确认 `num_obs=285`、`num_actions=12`）：
```bash
cd WMP && MAX_ITERS=5 MAX_ENVS=16 python train_capped.py \
  --task=go2_amp --headless --num_envs=16 --sim_device=cuda:0
```
4. G3：把 `reference/go2_migration/check_go2_depth.py` 放进 overlay；apply 后 `cd WMP && python check_go2_depth.py --task=go2_amp --headless`；要求 near fraction < 0.10，保存 `go2_depth.png`。
5. 短训练：
```bash
cd WMP && MAX_ITERS=300 MAX_ENVS=64 python train_capped.py \
  --task=go2_amp --headless --num_envs=64 --sim_device=cuda:0
```
记录 reward/nan/显存；ckpt 路径写进 STATUS。
6. 用 `play.py` 或 ckpt 录 rollout 视频，命令写进 STATUS。
## 必须产物
- 4 个 motion 文件 + checksum、`go2_depth.png`。
- 短训练 log/ckpt/视频/manifest；关键输出写进 STATUS。
## 退出条件
- G0~G3 全过；短训练无 nan；视频里 Go2 能站/走；WMP 无越界改动。
## 禁止
- FAIL 时改检查脚本；动作重定向；删 A1；用 MuJoCo XML；只跑 5 iter 就宣布完成。
